# Project Overview

This is an educational project for learning Python and OpenAI Codex.

# Working Guidelines

- Before modifying code, inspect the relevant files.
- Keep changes focused on the requested task.
- Avoid unrelated modifications.
- Prefer simple, readable code suitable for learning.

# Testing

- Run relevant tests when possible.
- If tests cannot run, explain why.
- Never claim tests passed unless they were actually executed.

# Communication

- Respond in Persian by default, even if the user's prompt is in English.
- If the user explicitly requests another language, use that language.
- Explain completed changes clearly.
- Summarize which files were changed.
- Report test results and any limitations.
- Do not claim that a file was read or a test was run unless it actually happened.
