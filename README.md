# ماشین‌حساب ساده با Python

این برنامه در Terminal دو عدد و یک عملگر دریافت می‌کند و پس از نمایش نتیجه یا خطا پایان می‌یابد. به Python 3 نیاز دارد و وابستگی خارجی ندارد.

## اجرا

در پوشهٔ پروژه دستور زیر را اجرا کنید:

```sh
python calculator.py
```

به‌ترتیب عدد اول، عملگر و عدد دوم را وارد کنید. اعداد منفی و اعشاری پشتیبانی می‌شوند؛ برای ممیز از `.` استفاده کنید. عملگرهای مجاز `+`، `-`، `*` و `/` هستند. پیام‌های برنامه انگلیسی هستند.

نمونه:

```text
Enter the first number: 9
Enter an operator (+, -, *, /): /
Enter the second number: 2
Result: 4.5
```

## تست دستی

برای هر ردیف برنامه را دوباره اجرا کنید:

| عدد اول | عملگر | عدد دوم | خروجی مورد انتظار |
|---|---|---|---|
| `2` | `+` | `3` | `Result: 5.0` |
| `7` | `-` | `10` | `Result: -3.0` |
| `-4` | `*` | `2.5` | `Result: -10.0` |
| `9` | `/` | `2` | `Result: 4.5` |
| `5` | `/` | `0` | `Error: Cannot divide by zero.` |
| `abc` | `+` | `2` | `Error: Please enter valid numbers.` |
| `2` | `+` | خالی (Enter) | `Error: Please enter valid numbers.` |
| `2` | `%` | `3` | `Error: Invalid operator. Use +, -, *, or /.` |

نمایش اعداد صحیح به شکل اعشاری مانند `5.0` طبیعی است، چون ورودی‌ها به `float` تبدیل می‌شوند.
